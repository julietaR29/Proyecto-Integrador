# 🧠 Proyecto Integrador - Programación en C++

Este proyecto fue desarrollado como trabajo integrador para la materia de programación.

## 📌 Descripción

Se trata de una aplicación en C++ que simula un juego de dados con múltiples funcionalidades, incluyendo:

- Gestión de datos
- Uso de funciones y modularización
- Cálculo de estadísticas
- Interacción mediante menú

## 🛠️ Tecnologías utilizadas

- Lenguaje: C++
- Entorno: Code::Blocks

## 📂 Estructura del proyecto

- `main.cpp`: punto de entrada
- `menu.cpp / menu.h`: navegación del programa
- `juego.cpp / juego.h`: lógica principal
- `datos.cpp / datos.h`: manejo de datos
- `estadisticas.cpp / estadisticas.h`: cálculos
- `funciones.cpp / funciones.h`: utilidades

## ▶️ Cómo ejecutar

1. Abrir el proyecto en Code::Blocks
2. Compilar (Build)
3. Ejecutar (Run)
